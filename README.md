# Nextcloud su Proxmox (LAN)

Questa documentazione spiega come configurare un server Nextcloud in una rete locale
utilizzando Proxmox, Docker e LXC.

## Obiettivi del progetto
- Creare un container LXC su Proxmox
- Installare Docker nel container
- Installare e configurare Nextcloud
- Gestire tutto nella rete locale senza esposizione verso Internet
