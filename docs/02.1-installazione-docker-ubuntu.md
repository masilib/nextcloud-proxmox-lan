# Installazione Docker + Portainer su Ubuntu Server Linux (LXC Proxmox)

Questa guida spiega come installare Docker su Ubuntu Server Linux e creare un container Portainer + Portainer Agent usando Docker Compose.

---

## 1️⃣ Aggiornare Ubuntu e installare utilità di base 

```bash
sudo apt update
```
> Installa prerequisiti
```bash
sudo apt install -y ca-certificates curl gnupg lsb-release
```

> Aggiungi chiave GPG Docker
```bash
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
```

> Aggiungi repository Docker
```bash
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```

> Aggiorna lista pacchetti e  Installa Docker e Docker Compose
```bash
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

> Verifica installazione
```bash
docker --version
docker compose version
```

---

## 2️⃣ Configurare Utente e abilitare Docker all'avvio e avviare il servizio

> Aggiungi utente al gruppo docker, applica modifiche, test Docker
```bash
sudo usermod -aG docker $USER
newgrp docker
docker run hello-world
```

> Abilita e avvia Docker

```bash
sudo systemctl enable docker
sudo systemctl enable containerd
sudo systemctl status docker

# Verifica stato
sudo systemctl status docker
```
---

## 3️⃣ Installare Docker Compose
```bash
# Crea directory

mkdir -p ~/portainer
cd ~/portainer
 
# Crea docker-compose.yml
cat > docker-compose.yml << 'EOF'
version: '3.8'

services:
  portainer:
    image: portainer/portainer-ce:latest
    container_name: portainer
    restart: always
    ports:
      - "9000:9000"
      - "9443:9443"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - portainer_data:/data
    networks:
      - portainer_network 

volumes:
  portainer_data:
    driver: local

networks:
  portainer_network:
    driver: bridge
EOF

# Avvia Portainer
docker compose up -d

# Verifica
docker compose ps
```

> Apri il browser su:

```
https://<IP_CONTAINER>:9443
```

- Login iniziale → crea utente admin
